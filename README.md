# 🔥 Привычки — трекер привычек с геймификацией

Веб-приложение для отслеживания привычек: отмечай выполнение каждый день, держи серии (streak), зарабатывай XP, повышай уровень и открывай достижения.

## Возможности

- **Аккаунты** — регистрация и вход по email + паролю (JWT), у каждого пользователя свои данные.
- **Гибкое расписание** — привычка по выбранным дням недели (например, Пн/Ср/Пт) или «N раз в неделю».
- **Streak** — серия подряд выполненных запланированных дней (для недельных целей — серия выполненных недель). Сегодняшний день серию не обрывает, пока он не закончился.
- **Календарь** — месячный календарь для каждой привычки; можно отметить или снять день за последние 30 дней.
- **XP, уровни и достижения** — 10 XP за отметку, 50 XP за достижение, 12 достижений.
- **Статистика** — тепловая карта активности, выполнение по неделям, прогресс по каждой привычке за 30 дней.
- **Напоминания** — браузерные Web Push-уведомления в заданное время, даже если вкладка закрыта.
- Светлая и тёмная тема (по настройкам системы), адаптивная вёрстка.

## Стек

| Часть | Технологии |

## Требования

- **Node.js 22.5 или новее** (нужен встроенный `node:sqlite`; проект проверен на Node 24).

## Быстрый старт

```bash
npm install
npm run dev
```

После запуска:

- клиент — http://localhost:5173
- API — http://localhost:3001 (клиент проксирует `/api` на него)

Открой клиент, зарегистрируйся и добавь первую привычку.

### Продакшен-режим

```bash
npm run build          # собирает клиент в client/dist
npm start -w server    # сервер отдаёт API и собранный клиент на http://localhost:3001
```

## Настройки (переменные окружения сервера)

Можно положить в `server/.env`.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3001` | Порт API |
| `JWT_SECRET` | генерируется и сохраняется в `server/data/jwt-secret.txt` | Секрет для подписи токенов. В продакшене задай свой |
| `DATA_DIR` | `server/data` | Где лежат база, VAPID-ключи и секрет |
| `VAPID_SUBJECT` | `mailto:admin@example.com` | Контакт для Web Push. Замени на свой email |

## Уведомления

1. Нажми 🔕 вверху экрана и разреши уведомления в браузере — придёт тестовое сообщение.
2. В настройках привычки включи «Напоминать» и выбери время.

Сервер раз в минуту проверяет привычки и присылает напоминание, если привычка запланирована на сегодня и ещё не отмечена. Время считается по часовому поясу браузера пользователя. Если сервер был недоступен в нужную минуту, напоминание придёт в течение часа после назначенного времени.

Web Push работает на `localhost` и на сайтах с HTTPS. Для публичного развёртывания нужен HTTPS.

## Как считаются XP и уровни

- XP = 10 × число отметок + 50 × число достижений. Значение вычисляется, поэтому снятие отметки аккуратно уменьшает XP.
- Уровень *n* начинается с 50·(n−1)² XP: 0, 50, 200, 450, 800, …
- Звания: Новичок, Ученик, Практик, Мастер, Эксперт, Легенда.
- Открытые достижения не отбираются, даже если потом снять отметки.

## API

Все маршруты, кроме регистрации и входа, требуют заголовок `Authorization: Bearer <token>`. Параметр `today` (дата пользователя `YYYY-MM-DD`) передаёт клиент.

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | Регистрация и вход, возвращают `token` и `user` |
| GET | `/api/me` | Текущий пользователь, XP и уровень |
| GET | `/api/habits` | Привычки со streak и статусом на сегодня |
| POST | `/api/habits` | Создать привычку |
| PUT | `/api/habits/:id` | Изменить привычку |
| DELETE | `/api/habits/:id` | Удалить привычку |
| PUT | `/api/habits/:id/checkin` | Отметить или снять день: `{ date, done }` |
| GET | `/api/habits/:id/checkins` | Даты отметок за период (`from`, `to`) |
| GET | `/api/stats` | Данные для статистики |
| GET | `/api/achievements` | Список достижений |
| GET / POST | `/api/push/key`, `/api/push/subscribe`, `/api/push/unsubscribe`, `/api/push/test` | Управление push-уведомлениями |

## Данные

Всё хранится в `server/data/` (папка в `.gitignore`): база `habits.db`, VAPID-ключи и JWT-секрет. Чтобы сбросить приложение, останови сервер и удали эту папку.
