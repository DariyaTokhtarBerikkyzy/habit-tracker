# Описание тестирования

## 1. Автотесты

Тесты написаны на встроенном `node:test` и находятся в `server/src`. Всего 57 тестов.

| Файл / группа | Что проверяет | Требования |
|---|---|---|
| `streak.test.ts` (5 тестов) | Расчёт серий: ежедневная серия, незавершённый сегодняшний день, обрыв при пропуске, будни с выходными, недельная цель «3 раза в неделю», пустая история | ФТ-9 |
| `api.test.ts` — «С-1: регистрация и вход» (11) | Регистрация, хеш bcrypt в БД, дубликат email (409), невалидные email и пароль (400), вход с верным и неверным паролем, 401 без токена и с неверным токеном | ФТ-1, ФТ-2, НФТ-1, НФТ-2 |
| «Обработка некорректного ввода» (3) | Битый JSON даёт 400, неизвестный маршрут — 404 в JSON, сервер продолжает работать после ошибок | НФТ-5 |
| «С-2: создание и изменение привычки» (13) | Создание по дням и «N раз в неделю», 7 вариантов невалидных данных, изменение, каскадное удаление отметок, несуществующий и нечисловой id (404), изоляция чужих привычек | ФТ-4 … ФТ-7, НФТ-3 |
| «С-3 и С-4: отметки, серии, календарь» (12) | Отметка и XP, идемпотентность повторной отметки, снятие отметки, серия 3 дня, обрыв серии и рекорд, выборка дат для календаря, 6 вариантов некорректной отметки (будущее, старше 30 дней, формат даты, несуществующая дата, тип `done`, пустое тело) | ФТ-8 … ФТ-10 |
| «С-5: XP, уровни, достижения» (4) | Начисление XP и бонусов, уровень, список из 12 достижений, «Коллекционер», «Идеальный день» | ФТ-11, ФТ-12 |
| «С-6: статистика» (2) | Структура ответа (8 недель, тепловая карта, данные по привычкам), отсутствие чужих данных | ФТ-13, НФТ-3 |
| «С-7: напоминания» (5) | Отправка в окно времени и только один раз в день, отсутствие отправки раньше срока, позже чем через час и для уже выполненной привычки, подписка и отписка, выдача публичного ключа | ФТ-14, ФТ-15 |
| «Демо-данные» (1) | Создание демо-пользователя, вход под ним, идемпотентность повторного запуска | README, «Тестовые учётные записи» |
| «НФТ: время ответа» (1) | `GET /api/habits` и `GET /api/stats` быстрее 500 мс при 20 привычках и 3 650 отметках | НФТ-4 |

Тесты API запускают реальное Express-приложение на свободном порту с временной базой SQLite, которая удаляется после прогона. Отправка push проверяется на уровне логики планировщика (запись в журнал напоминаний); доставка в браузер проверяется вручную (ТК-15, ТК-16).

## 2. Команда запуска

Из корня репозитория (нужен Node.js 22.5+ и `npm install`):

```bash
npm test
```

Запуск без вывода в корень:

```bash
npm test -w server
```

На момент написания документа все 57 тестов проходят. Проверка типов: `npm run typecheck`.

## 3. Тест-кейсы ручной проверки

Предусловие для всех кейсов: приложение запущено по инструкции из README и открыто на http://localhost:8080 в Chrome или Edge. Если не указано иное, используется демо-пользователь `demo@test.ru` / `demo123`.
