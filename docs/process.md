# Распределение работы и процесс

## 1. Распределение работы

Проект выполнен одним участником, который совмещает все роли.

| Участник | Роль | Выполненные задачи |
|---|---|---|
| Дария Тохтар ([GitHub](https://github.com/DariyaTokhtarBerikkyzy)) | Тимлид | Выбор темы и стека, определение набора функций первой версии (streak, XP и достижения, статистика, гибкое расписание, напоминания), порядок работы |
| | Аналитик | Пользовательские сценарии С-1 … С-7, функциональные и нефункциональные требования ([tz.md](tz.md)) |
| | Backend | Схема SQLite, REST API, регистрация и вход (bcrypt, JWT), расчёт серий, XP и достижений, планировщик Web Push |
| | Frontend | Интерфейс на React: вход, список привычек, форма, календарь, статистика, награды, подписка на уведомления, Service Worker |
| | Тестировщик | Автотесты логики серий и API (57 тестов), ручные тест-кейсы ТК-1 … ТК-17 ([testing.md](testing.md)) |
| | DevOps | Dockerfile, `docker-compose.yml`, `.env.example`, демо-данные для запуска |

Использование ИИ при выполнении задач описано в [ai.md](ai.md).

## 2. Доска задач

Доска задач — GitHub Issues: https://github.com/DariyaTokhtarBerikkyzy/habit-tracker/issues (веха [MVP](https://github.com/DariyaTokhtarBerikkyzy/habit-tracker/milestone/1)). Метки: роль или область (backend, frontend, тесты, devops, документация, аналитика), «сценарий» для С-1…С-7, «план развития» для задач вне MVP. Закрытые задачи — выполненная работа, открытые — то, что осталось (ручная проверка push, презентация) и планы развития.

Доска заведена в конце работы по итогам выполненных задач, а не в начале планирования.

## 3. Работа с Git

- Репозиторий: https://github.com/DariyaTokhtarBerikkyzy/habit-tracker
- Участник в проекте один, поэтому используется единственная ветка `main`; изменения коммитятся в неё напрямую, без pull request и ревью.
- Коммиты делаются законченными порциями, по смыслу: первая версия приложения, затем адаптация под требования проекта (Docker, демо-данные, автотесты API, документация).
- Актуальную историю можно посмотреть командой `git log --oneline`; таблица выше соответствует ей.
- Файл `.env`, база данных и ключи в репозиторий не попадают (`.gitignore`).
